# 통합접수창구 · Firebase 실제 연결판

이 폴더 안의 index.html, .nojekyll, README.md만 GitHub 저장소의 최상위에 업로드하세요. 폴더명 자체가 업로드 경로 앞에 붙으면 안 됩니다. 기존 파일은 같은 이름으로 교체하고 다른 개발 파일은 삭제하지 않아도 됩니다.

Pages 설정: Deploy from a branch → main → /(root).

가상 명단은 포함하지 않습니다. Firebase에 등록한 실제 이메일/비밀번호로 로그인합니다. 최초 관리자 권한은 확인된 기존 관리자 UID에만 발급합니다. 나머지 계정은 관리자 앱에서 소속 기관과 함께 발급합니다.

처음 로그인하기 전에 상위 폴더의 설치 안내대로 Firestore 보안 규칙을 먼저 적용해야 합니다. 구글 시트의 Apps Script까지 설치하고 열 연결을 마친 뒤 실제 접수자가 보입니다. 파일 업로드만으로 실제 시트가 연결되지는 않습니다.

Firebase 웹앱 공개 설정만 포함하며 관리자 비밀번호, 서비스 계정 비밀키, 신청자 이름/응답은 포함하지 않습니다. 사용자 관리 및 데이터 저장은 Firebase에서 처리하며 GitHub에는 신청자 정보를 저장하지 않습니다.
